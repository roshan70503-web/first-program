# Roshan Shah — Portfolio

Next.js 14 · TypeScript · Tailwind CSS · Lucide icons

## Run locally
```bash
npm install
npm run dev      # http://localhost:3000
```

## Edit content
Everything lives in `data/content.ts` (text, skills, projects, links). Replace `public/resume.pdf` to update the download. Add a photo to `public/` and set `profile.photo`.

## Deploy to Vercel
1. Push this folder to a GitHub repository.
2. Go to vercel.com → Add New → Project → import the repository.
3. Keep the defaults (Framework: Next.js) and click Deploy.
Every later `git push` redeploys automatically.
